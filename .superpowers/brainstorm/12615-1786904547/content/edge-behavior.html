Planetnik · Code City · Dependency routes

When should dependency roads appear?

Edges are evidence, not decoration. The default scene should preserve parcel legibility; routes should become prominent when a reader has a question to investigate.

A · Always-on network

All component edges visible

Network-first. Useful for topology, but dense repositories quickly become a road tangle.

Recommended

B · Selection path

Selected context/building reveals its routes

Inspector-first. Keep the city calm; selecting a parcel or building reveals only its connected evidence paths.

C · Impact routes

Edges visible only in Impact lens

Analysis-first. Very clean at rest, but dependency evidence is hidden until the reader changes lens.
